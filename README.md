# 🎶 AI Lyrics Generator

An AI-powered web app that generates song lyrics based on user input including theme keywords, genre, language, tempo, and scale. The app uses **GPT-Neo** to generate creative and multilingual lyrics and **Streamlit** for the interactive web interface.

Whether you're a songwriter seeking inspiration or just exploring the creative potential of AI, this tool can help you come up with unique song lyrics in seconds!

---

## 🚀 Features

- **Keyword-based lyric generation**: Provide a set of keywords to guide the AI in creating lyrics.
- **Genre selection**: Choose from various genres such as Pop, Rock, Hip-Hop, EDM, and more.
- **Multilingual support**: Generate lyrics in multiple languages (e.g., English, Hindi, Spanish) using **Googletrans**.
- **Scale and tempo customization**: Control the musical context by selecting the scale (C Major, A Minor, etc.) and tempo (Slow, Fast, etc.).
- **Interactive web interface**: Built using **Streamlit** for an easy-to-use, responsive interface.
- **GPT-Neo powered lyrics generation**: Harness the power of **GPT-Neo** to generate natural-sounding song lyrics.

---

## 📦 Tech Stack

- **Python**: The main programming language used.
- **Streamlit**: For building the web interface.
- **Hugging Face Transformers**: Using **GPT-Neo** for natural language processing and text generation.
- **Googletrans**: For multilingual support to translate lyrics.
- **GitHub**: For version control and hosting the project.

## 🛠 Installation and Setup

### Prerequisites

Ensure you have **Python 3.7+** installed on your system. You can verify this by running:

```bash
python --version
```

### 1. Clone the repository:

```bash
git clone https://github.com/your-username/ai-lyrics-generator.git
```

### 2. Navigate to the project directory:

```bash
cd ai-lyrics-generator
```

### 3. Install dependencies:

Make sure you're in the project directory and run the following command to install all required packages:

```bash
pip install -r requirements.txt
```

## 🎮 How to Use

### 1. Start the Streamlit app:

```bash
streamlit run lyrics_generator.py
```

This will launch the app in your browser. You can now input the following details to generate lyrics:

- **Keywords**: Words that the song should be based on (e.g., "love, night, dream").
- **Genre**: Choose from a variety of music genres like Pop, Rock, Hip-Hop, etc.
- **Language**: Select the language for the generated lyrics (e.g., English, Hindi).
- **Scale**: Pick a musical scale (e.g., C Major, A Minor).
- **Tempo**: Choose a tempo (e.g., Slow, Fast).
